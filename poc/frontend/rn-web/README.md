# B1 — React Native Web

Même contenu fonctionnel que A1, mais les contrôles sont des primitives React Native.
Pour servir sur le web, configurer `react-native` vers `react-native-web` dans Vite.
Audit à lancer sur le build de production avec axe DevTools ou Lighthouse ; ne pas comparer
un serveur de développement à un build de production.
