# C1 — Angular + Ionic

POC à réaliser dans un projet généré par `ionic start area-poc blank --type=angular`.
Reproduire les champs et textes de A1 avec `ion-input`, `ion-button` et `ion-select`.
Build Android : `ionic cap add android && ionic cap sync android && cd android && ./gradlew assembleDebug`.
Noter que le rendu mobile est un WebView, point explicitement évalué par la décision technique.
